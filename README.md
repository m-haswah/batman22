# محاضرات batman

تطبيق ويب (PWA) يسمع صوت مكالمة Teams، يرسله إلى Gemini على مقاطع قصيرة، ويعرض النص والنقاط المهمة وأجوبة أسئلة المتحدث فوراً، ثم يكتب ملخصاً نهائياً. لا يوجد build ولا npm: ملفات ثابتة فقط.

## النشر على GitHub Pages
1. أنشئ مستودعاً وارفع محتويات هذا المجلد إلى الفرع `main`.
2. Settings ← Pages ← Source: **GitHub Actions**.
3. بعد انتهاء الـ workflow يظهر الرابط `https://USERNAME.github.io/REPO/`.

## تجربة محلية
```bash
python3 -m http.server 3000   # ثم افتح http://localhost:3000
```

## مفتاح Gemini
من https://aistudio.google.com/apikey ثم الصقه في «الإعدادات». يُحفظ في متصفحك فقط، ولا تضعه في الكود.

## التقاط مكالمة Teams (كمبيوتر، Chrome أو Edge)
- افتح Teams من المتصفح (teams.microsoft.com) وانضم للمكالمة.
- في التطبيق اختر «مكالمة Teams» ← ابدأ التسجيل ← اختر **تبويب Teams** وفعّل «مشاركة صوت التبويب».
- تطبيق Teams على ويندوز: اختر الشاشة كاملة مع صوت النظام (سيلتقط أي صوت آخر شغّال).
- «Teams + صوتي» يضيف الميكروفون ليسمع صوتك أيضاً.
- الهاتف لا يسمح بالتقاط صوت التطبيقات، استخدم «الميكروفون».
- الفيديو لا يُسجَّل ولا يُرسل: المتصفح يطلب مشاركة صورة مصغّرة فقط ليفتح نافذة الاختيار.
